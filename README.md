# SIM-Barang

## 1. Gambaran Umum Proyek

SIM-Barang (Sistem Informasi Manajemen Barang) merupakan proyek aplikasi berbasis web yang dirancang untuk membantu pengelolaan data barang, seperti pencatatan barang, pemantauan stok, dan pencarian informasi barang.

## 2. HTTP Request

HTTP Request adalah permintaan yang dikirimkan oleh client, seperti browser, kepada server untuk meminta atau mengirimkan data.

Metode HTTP yang umum digunakan:
- GET: Mengambil data dari server.
- POST: Mengirimkan data baru ke server.
- PUT: Memperbarui data yang sudah ada.
- DELETE: Menghapus data.

## 3. HTTP Response
 
HTTP Response adalah jawaban yang dikirimkan server kepada client setelah menerima dan memproses permintaan.

Contoh status code HTTP:
- 200 OK: Permintaan berhasil.
- 201 Created: Data berhasil dibuat.
- 400 Bad Request: Permintaan tidak valid.
- 404 Not Found: Halaman atau data tidak ditemukan.
- 500 Internal Server Error: Terjadi kesalahan pada server.

## 4. Alur HTTP Request dan Response

1. Pengguna mengakses aplikasi melalui browser.
2. Browser mengirimkan HTTP Request ke server.
3. Server memproses permintaan.
4. Server mengirimkan HTTP Response kepada browser.
5. Browser menampilkan hasil kepada pengguna.

## 5. Perangkat Pengembangan

- Visual Studio Code sebagai editor kode.
- Git sebagai sistem kontrol versi.
- GitHub sebagai tempat penyimpanan repositori.
- Laragon atau XAMPP sebagai lingkungan server lokal.

## 6. Tujuan Proyek

Proyek SIM-Barang bertujuan untuk mempelajari dasar pengembangan aplikasi web, penggunaan Git dan GitHub, serta komunikasi antara client dan server melalui protokol HTTP.
